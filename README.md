This repository presents the data used to replicate the results of Aguilar and Lahura (2025), “When Expectations Matter: The Role of Fiscal Foresight in Government Spending Shocks in Peru.”

The file Aguilar_Lahura_2025_data.xlsx contains the variables used in the main estimation and in robustness exercises 1, 2, and 3.

The previous working paper version is available at:
https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5164125

and
https://www.bcrp.gob.pe/docs/Publicaciones/Documentos-de-Trabajo/2024/documento-de-trabajo-002-2024.pdf
